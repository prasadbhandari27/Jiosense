# OneUI scale colours

Part of the OneUI Figma foundations set. Invoke the orchestrator `the `oneui-figma-foundations` skill (get_skill "oneui-figma-foundations")` for the full workflow, or this skill when you only need this topic. Core rules live in `get_skill_reference("oneui-figma-foundations", "references/oneui-figma-foundations-core.md")`.

# Scale colours

Every step of every scale, as sRGB hex.

**Grep for the scale you need — do not read this whole file.** `grep -A2 '^### indigo' scale-colours.md`

These are the values the tokenator writes into `19 Primitives`. In a live file, prefer reading the
colour back from Figma (see `writing-to-figma.md`, `resolveForConsumer`) — that cannot go stale.
Use this table to explain or check a colour offline, and to compute contrast when you need to.
